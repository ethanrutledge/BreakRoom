# Break Room

A small retro games lounge for Windows — chess, cards, pool, mini golf, puzzles and more, in one window.

## Download & play

1. Click **`BreakRoom.bat`** above, then the **Download** button (or the **…** menu → Download).
2. Double-click the downloaded `BreakRoom.bat`.

The first run sets itself up automatically (it installs Python if your PC doesn't have it — this can take a minute, and only happens once). After that the game opens straight away. Your progress is saved in a file next to `BreakRoom.bat`.

If no window appears, open `break_room_error.txt` in the same folder — it says what went wrong.

> **Windows SmartScreen** may warn about an unrecognized app the first time. Choose **More info → Run anyway**.
